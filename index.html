How to set up error handling in n8n

  1. Import both the generated workflow and the Default ErrorLog workflow into n8n.
  2. Open your main workflow in the n8n editor.
  3. Click the Settings (three dots) in the top right, then select Settings.
  4. In the Error Workflow dropdown, select your errorlog workflow (usually named errorlog).
  5. Click Save to apply the changes.
This ensures that any errors in your main workflow will trigger the errorlog workflow for notifications or custom handling.
